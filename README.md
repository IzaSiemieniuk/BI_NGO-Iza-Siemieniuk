# BI_NGO-Iza-Siemieniuk

## Working Dogs Foundation - Analiza danych 📊
W ramach akcji #BI_NGO przeprowadzono analizę danych fundacji Working Dogs Foundation.
### O analizie
Analiza obejmuje dane za lata 2023-2025 i koncentruje się na strukturze przychodów fundacji - źródłach finansowania, dynamice wzrostu oraz zmianach w czasie. W ramach projektu powstały wizualizacje w Pythonie oraz grafiki przygotowane w Flourish i Canvie.
